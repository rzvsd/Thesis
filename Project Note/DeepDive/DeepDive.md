# Deep Dive Revamp Summary

Deep Dive Revamp established the institutional-report foundation through M7.

The follow-on path now has two linked upgrades:

- M8 keeps the product entrypoint named `Deep Dive` while making the default output a full due diligence report instead of a memo-heavy summary
- M9 upgrades that due-diligence default into a verbose editorial artifact with HTML/CSS-to-PDF export, issuer metadata, and mobile summary-first inline expand

These follow-on upgrades lock:

- a canonical `due_diligence` layer with six sections:
  `financial_analysis`, `competitive_positioning`, `management_and_governance`, `risks_and_challenges`, `growth_opportunities_and_outlook`, and `valuation_and_thesis_stance`
- `investment_memo` retained as a short compatibility summary layer
- a 10-14 page HTML/CSS-to-PDF editorial target for full-data reports
- issuer metadata in the report surface and metadata appendix
- a mobile summary-first reader with inline expand-for-proof behavior
- strict omission honesty across every section

The governing path is now `M0-M7` foundation plus `M8` and `M9` as follow-on upgrades.
