# DDR-004 - PDF Is A Serious Artifact

**Status:** Accepted
**Date:** 2026-04-20

---

## Decision

The Deep Dive PDF is a report artifact with pages, exhibits, appendix, source notes, and layout QA. It is not a printout of the mobile screen.

---

## Rationale

The user explicitly wants the Deep Dive to feel like a serious research report. The reference report demonstrates the importance of page hierarchy, exhibit discipline, appendix tables, and visual clarity.

---

## Consequences

- M5 owns PDF generation and visual proof.
- PDF output must be rendered and inspected before closeout.
- Mobile can stay concise because the PDF carries the full artifact.

---

## Guardrails

- No broken tables.
- No clipped text.
- No fake charts.
- No missing source notes.
- No copied proprietary layout or branding.
