# Shared Deno code by area

Each folder here belongs to one milestone (see `docs/rebuild/OWNERSHIP.md`): `store`, `auth`, `email`,
`pulse`, `reports` (M1); `jobs` (M2); `research`, `evaluators` (M3); `exports`, `push`, `billing` (M4). Logic
copied from `apps/` goes here unchanged where possible. Any milestone may import from any folder; only the
owner edits it.
